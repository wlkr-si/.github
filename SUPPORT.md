# Help with a project

Start with the project's README and documented limitations. Search existing issues, then open an issue in the affected repository with a minimal example and your version and operating system.

Browse the [project directory](https://wlkr.si/work) to find the right project. Do not post passwords, API tokens, private account information or full production logs in public issues. For a security concern, follow the affected repository’s security policy or the [shared security reporting guide](SECURITY.md).

Projects set their own support scope. There is no guaranteed response time or implied support contract.
