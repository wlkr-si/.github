# Report a security concern

Email [security@wlkr.si](mailto:security@wlkr.si) with the affected project, version or commit, impact, and the smallest safe reproduction. This is the security contact published on [WLKR.SI](https://wlkr.si/about).

Keep vulnerabilities, credentials, private account details and production data out of public issues. Remove secrets from examples and logs. Use a reduced example with synthetic data where possible.

A project’s own security policy takes precedence. Check its README and release notes for version-specific maintenance information.
