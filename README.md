# WLKR.SI shared standards

The organisation profile and default contribution files for [WLKR.SI](https://wlkr.si).

- [Studio profile](profile/README.md)
- [Contribution guide](CONTRIBUTING.md)
- [Studio standards](docs/STANDARDS.md)
- [Support guide](SUPPORT.md)
- [Security reporting](SECURITY.md)
- [Pull request template](PULL_REQUEST_TEMPLATE.md)
- [Issue forms](.github/ISSUE_TEMPLATE)

Repositories use these community defaults when they do not supply their own. A project's own instructions and license take precedence. The profile uses the canonical Open Lens artwork from the [studio brand suite](https://wlkr.si/brand).

Find software in the [project directory](https://wlkr.si/work). Check an organisation's public entry points with [studio-check](https://github.com/wlkr-si/studio-check).
